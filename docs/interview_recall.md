# Interview Recall

Use this as a concise recall sheet when explaining the project to a new visitor, collaborator, or future Codex session.

## Short pitch

Codex Skills From Scratch helps beginners turn repeatable Codex workflows into reusable Skills with templates, audit checks, safe installation, and project history.

## User problem

Codex can do useful work in one session, but fresh sessions need reusable workflow knowledge to be externalized. Without a small structure, lessons turn into scattered prompts, oversized instructions, or unreviewed local changes.

## Project answer

This repo provides a working starter system:

- Skill Maker as a meta Skill;
- a task Skill template;
- prompt templates;
- a dry-run-first installer;
- Local and CI audit modes;
- examples that are not installed by default;
- project logs, troubleshooting notes, and release notes.

## Differentiators

- It teaches the workflow by shipping the workflow.
- It keeps Skill changes reviewable through Git.
- It separates repo source from installed user-level Skills.
- It uses audits as safety gates.
- It keeps examples separate from live Skill installation.

## Boundaries

- Not an official OpenAI repo.
- Not a secret manager.
- Not a giant Skill catalog.
- Not an autonomous agent without human supervision.
- Not a place for sensitive values or local-only private files.
